**Date:** 2026-10-28
**Status:** requested work and observed results are separated below

## Human-approved instruction

Pivot the active product from BreathBloom to FocusBloom while preserving the
submitted Part 3.1 report, prompt records 01–06, original Figma comparison, and
Git history. Establish FocusBloom as a fictional low-input attention-and-
perspective coursework prototype; create editable Figma references; design the
new application states, version-2 data model, `/api` surface, and two bounded

public repository if `focusbloom` is available; and publish the pivot on the
existing feature branch without changing `main`.

for project/tool continuity.

Required boundaries included: fictional scenarios only; no therapy, diagnosis,
crisis detection, monitoring, clinical/effectiveness claims, scores, streaks,
voice/audio, real credential, runtime database creation, live Gemini call, full
frontend/backend implementation, history rewrite, second repository, force push,
or merge to `main`.

## Requested design and plan

- Focus Garden with optional no-typing visual-attention activities.
- Perspective Studio with the five-step one-minute cognitive-reframe sequence,
  fictional-example path, and optional Perspective Lens.
- Optional user-authored Next-Step Seed.
- Factual History Garden and bounded Garden Guide.
- Seventeen explicit application states, a normalized version-2 schema, exact
  routes, bounded Perspective alternatives, and strict two-request history RAG.
- One primary action per screen, progressive disclosure, visible optionality,
  and continuously available Support.
